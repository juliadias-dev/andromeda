    # 📁 Portfólio Pessoal - Front-End 

Este é meu projeto final desenvolvido durante o curso **Tecnologia Web - Engenharia da Computação (Front-End)**. Trata-se de uma ficha/portfólio temática da minha heroina Andromeda, apresentando suas informações, atributos, inventário, conquistas e formas de contato.


---

## 📌 Sobre o Projeto

Este site foi criado com foco em aplicar os conhecimentos de **HTML**, **CSS**,, **Flexbox**, **responsividade** e **publicação com GitHub Pages**.
O projeto foi organizado para apresentar:
- *Sobre o Herói:* Informações da história e imagem principal.
- *Atributos & Habilidades:* Barras de progresso e lista de habilidades com ícones.
- *Inventário:* Exibição dos itens em grade com raridade e descrição.
- *Status & Conquistas:* Métricas detalhadas do personagem.
- *Contato com a Guilda:* Links úteis para interação.


---

## 🧰 Tecnologias Utilizadas

## Tecnologias Utilizadas

- **HTML5:** utilizado para estruturar o site com tags semânticas, organizando as seções do perfil interativo da personagem.
- **CSS3:** responsável pela estilização da interface, utilizando Flexbox, CSS Grid e media queries para adaptar o layout a diferentes tamanhos de tela.
- **Google Fonts:** utilizado para importar as fontes **Cinzel** e **EB Garamond**, reforçando a identidade visual medieval e sombria do projeto.
- **Font Awesome:** utilizado para adicionar ícones à interface, facilitando a identificação visual de elementos.
- **Git e GitHub:** utilizados para o controle de versão, armazenamento do código-fonte e hospedagem do site.
